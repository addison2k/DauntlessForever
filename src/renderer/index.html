        How this works
        
  
          
    
        1. Game files. Press Download and the launcher fetches that exact build from Epic's servers (11 to 15 GB; you need about twice that free while it runs). Already have the game? "More" lets you point at the folder instead.
          2. 
    
        2. Set-up. A black window opens and asks one or two questions (press Enter for the defaults). It installs Node.js if needed, puts two files into the game folder (originals are kept, never deleted) and makes your offline account.
          3. 
    
        3. Play. Starts the local backend and the hidden game servers (about a minute), then the game. Closing the game closes the rest.
          4. 
  
        
  
        If something goes wrong
        
  
          
    
        • Stuck, or "a Dauntless process is running": press "Stop everything", then Play again.
          • 
    
        • "The game folder is missing files": the game was repaired or updated. Press Set up again; it only fixes what is missing.
          • 
    
        • If Windows asks whether Node.js or Dauntless may use the network, click Cancel. Everything stays on your PC.
          • 
    
        • Windows SmartScreen on first start: "More info" then "Run anyway". The launcher is not signed; signing costs money the project does not spend.
          • 
    
        • Asking for help: "More" then "Get the logs", and send the two zips. Your PC name and user name are blanked out in them.
