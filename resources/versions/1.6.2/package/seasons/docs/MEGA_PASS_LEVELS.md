# Mega Hunt Pass: all 400 levels

Every Hunt Pass season from Frostfall (2018) to Time Strike (2021), plus the winter 2020–21 event passes, in release order. The **Elite** row (the one the game shows) holds the season cosmetics, and each season ends on its Ultra or finale level. The **Free** row pays one dye per level, 100 Rams, a Common core every 5 levels, an Uncommon core every 10 and a Rare core every 50. The metagame pays both rows automatically as you level. Items marked *name from game text* have their real name only in the game's string tables, so they show properly in game.
